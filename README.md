## Introduction

Earthquake prediction is a challenging task, and this project explores the use of machine learning techniques to forecast seismic events. The model is built using Python, leveraging libraries such as scikit-learn and pandas.

## Features

- Collects seismic data from reliable sources.
- Preprocesses and cleans the data.
- Implements various machine learning algorithms for earthquake prediction.
- Provides an evaluation of model performance.
- User-friendly interface for interacting with the model.

## Requirements

- Python 3.x
- NumPy
- pandas
- scikit-learn
- Matplotlib
- Jupyter Notebook (optional, for interactive development)

## Installation

1. **Clone the repository:**

    ```bash
    https://github.com/anthony40527/Earthquake-prediction-model-using-python.git
    ```

2. **Install the required dependencies:**

    ```bash
    pip install -r requirements.txt
    ```

## Usage

1. **Navigate to the project directory:**

    ```bash
    cd earthquake-prediction
    ```

2. **Run the prediction model:**

    ```bash
    python predict_earthquakes.py
    ```

3. **Follow the on-screen instructions to input data and receive predictions.**

## Data

The seismic data used in this project can be found in the `data` directory. Ensure the data is up-to-date and reliable for accurate predictions.

## Model Training

To retrain the model or experiment with different algorithms, refer to the Jupyter Notebook `train_model.ipynb`. This notebook contains the step-by-step process of data preprocessing, model training, and evaluation.

## Evaluation

The model's performance is evaluated using metrics such as accuracy, precision, recall, and F1-score. Results are displayed both in the terminal and saved in the `results` directory.

## Results

The final results and performance metrics are documented in the `results` directory. Charts and graphs illustrating the model's predictions are also available for analysis.
